# Code

Requirements: Python 3.10 or later, with `numpy` and `python-sat` (`pip install -r requirements.txt`). A C compiler is needed for `quadratic/`, `elliptic/` and `five_qubit/anneal.c`. CaDiCaL and drat-trim are needed only for the DRAT check.

Every script exits with a non-zero status if a check fails.

| File | What it checks or computes | Time |
|---|---|---|
| `verify_facts.py` | Every finite fact used in the paper: counts of quadrics, points, lines and negative lines; signs from the phase rule and from 16×16 matrix products; the 40 320 doilies of `Q_0` and their 384-fold cover; the 10 grids of each doily, 4 through each line, 2 through two intersecting lines; oddness of all 67 200 grids; the witness and its structure; transport of the witness to all 136 hyperbolic quadrics. `--brute` also computes the degree 3 of every doily over its 2^15 assignments. | < 1 min (+ a few min with `--brute`) |
| `independent_check.py` | A second implementation, written separately, of the counts, the doily bound (by brute force) and the witness. Signs come from the Pauli multiplication table. | ~1 min |
| `w72.py`, `doilies.py` | The four-qubit space W(7,2) with signs from Pauli matrices, and the doilies of a hyperbolic quadric with their exact degrees | |
| `find_witness.py` | Local search for an assignment with 315 violated lines. It writes `witness_found.json` (the committed witness is `witness.json`) | seconds |
| `witness.json` | The witness: an assignment of the 135 points of `Q_0` violating exactly 315 lines | |
| `enumerate_optimal.py` | SAT enumeration of all optimal violated sets. It writes `optimal_sets.json`, and with `--cnf` the final formula `final.cnf` for a DRAT check | < 1 min |
| `optimal_structure.py` | Orbit of the witness's violated set under O⁺(8,2) (240 sets), realisability of each by linear algebra, equality with the SAT list, an isomorphism with DW(5,2) found and checked for each of the 240 sets, and a check of the stored isomorphism `dw52_isomorphism.json` for the witness (`--find` recomputes it) | seconds |
| `optimal_sets.json`, `dw52_isomorphism.json` | Outputs of the two scripts above | |
| `drat/` | The DRAT check of the final unsatisfiable formula: `check.sh` and its output `check.log` (CaDiCaL proof, verified by drat-trim). If `cake_lpr` (https://github.com/tanyongkiam/cake_lpr) is on the PATH, `check.sh` also converts the proof to LRAT with drat-trim and checks it with this verified checker; `check_cake_lpr.log` is the output of such a run. The proofs themselves (39 MB DRAT, 22 MB LRAT) are regenerated, not stored | ~2 min |
| `sat_ablation.sh`, `sat_ablation.log` | The encoding comparison of the paper: the four combinations of doily family (2520 or 40 320) and pair clauses, each with a 30-minute limit (`enumerate_optimal.py --family=all --no-pairs`, …) | up to 2 h |
| `sat_direct.py`, `sat_direct.sh`, `sat_direct.log` | Baselines without the paper's mathematics: MaxSAT (RC2) and SAT with "at most 314 violated lines" (totalizer), each with a 30-minute limit | up to 1 h |
| `general_bounds.py` | The table of the lower bounds ⌈L/5⌉ and ⌈5L/17⌉ for all quadrics and W, N = 3..7, with direct counts for N ≤ 5 | < 1 s |
| `elliptic/` | deg Q⁻(7,2) = 315 and deg W(7,2) = 1575. `run.sh` generates the signed instances (`gen_instances.py`), writes the parabolic complement in pair coordinates with signed symmetry generators (`mkz.py`, `group.py`) and checks it against the stored `zdata.txt`. It then runs the orbit enumeration and branch and bound `zorb.c` (467 orbits, minimum 216 attained by one orbit, next value 220), and a second run with another vector v and other generators. Finally it runs a separately written NumPy brute force on six orbits (`brute_check.py`) and the averaging and transport checks (`verify_avg.py`: 96 of the 136 complements contain each line; signed reflections reach all 136; signed transvections carry the quadric to all 120 elliptic quadrics of W(7,2), each W-line in 24). `run_exact.sh` then proves deg Q⁻(7,2) ≥ 315: `zcount.c` lists the 425 298 leaves (z, r) with f ≤ 251 (every other assignment violates ≥ f + 63 ≥ 315 lines, since the parabolic section has degree 63), and `inner_bb.c` bounds the remaining problem on the parabolic section of each leaf by Lagrangian decomposition over its doilies (`hstruct.py`, `leafinfo.py`), with branching where needed. Run 1 uses v = 1 and the 336 linear doilies, run 2 v = 253, other generators and the 1008 quadratic doilies. `brute_count.py` recounts the leaves of all 294 orbits, `lagrange_check.py` recomputes 1000 bounds in NumPy, and `witness_315.py` checks an assignment with 315 violated lines. `invariant_elliptic.py` shows that the smallest unsatisfied configurations invariant under GL(3,2) × C₃ (the stabiliser of two disjoint generators, acting as CNOT-type maps) have 315 lines, built on the incidence graph of PG(2,2) | ~20 min; `run_exact.sh` hours on 3 cores |
| `five_qubit/` | The five-qubit results. `invariant.py N` lists the unsatisfied configurations of Q⁺(2N−1,2) invariant under GL(N,2), the smallest one per point kind, and an explicit assignment checked against it (21, 315, 6975 for N = 3, 4, 5; 138 663 for N = 6). `sections.py ±` checks every elliptic section of Q^±(9,2) (sign class equal to W(7,2), uniform covering) and prints the averaging bounds 6975 and 5775, and the number of lines of the 6975-configuration in each section (always 315). `anneal.c` with `dump_instance.py` runs simulated annealing (upper bounds only) | seconds to 4 min |
| `quadratic/` | Exhaustive search over the 2^28 quadratic assignments: none violates fewer than 532 lines (`./run.sh`) | seconds |

Run the scripts from this folder. `verify_facts.py`, `enumerate_optimal.py`, `optimal_structure.py` and `quadratic/prepare.py` share the integer encoding of `verify_facts.py`. `w72.py`, `doilies.py`, `independent_check.py` and `find_witness.py` use tuples, as does `witness.json`.
